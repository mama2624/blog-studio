# gems/ — 제미나이 스킬 지침 정본

제미나이(Gemini) 스킬 편집기에 붙여넣는 **지침 전문**을 저장소에 두는 곳입니다. 스킬은 폴더·첨부를 읽지 못하므로(missing_files) 판(版)을 글자 단위로 관리합니다.

| 파일 | 무엇 |
|---|---|
| `keyword-gem-original-062624.txt` | **정본.** `mama062624@gmail.com`의 `실시간-키워드-제목-발굴-젬` 지침 |
| `keyword-gem-copy-062624.txt` | `mama2624@gmail.com`의 같은 이름 사본 지침 — **첫 줄만** 다르고 나머지는 정본과 같다(스크립트가 만든다) |
| `keyword-gem-meta.json` | 두 파일의 글자 수·bytes·sha256·줄 수 (테스트가 이 값을 대조) |

## 다시 만들기

```bash
python3 repos/blog-studio/tools/build_keyword_gem.py
```

정본(`...-original...txt`)만 고치고 위 스크립트를 돌리면 사본·붙여넣기 파일(`work/bs253/keyword-gem-v253-*.txt`)·`keyword-gem-meta.json`이 한 번에 맞춰집니다.
